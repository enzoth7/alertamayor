# Descubrimiento conservador de posibles ELEPEM

La adaptación local del starter está documentada en
`docs/ADAPTACION_DISCOVERY_STARTER.md`.

Esta rama conserva `public.residencial_discovery_candidates` como cola privada,
no aplica migraciones nuevas y no publica candidatos automáticamente. El
matching incorporado funciona únicamente con archivos locales y siempre deja
la decisión final a una revisión humana.
