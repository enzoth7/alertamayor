# Alerta Mayor - prototipo ELEPEM v0.1

Abra `index.html` con doble clic. La aplicación funciona sin servidor y utiliza una copia local de Plotly.

## Contenido

- `810` sedes probables unificadas.
- `1357` registros de fuente.
- Mapa interactivo, buscador y filtros.
- CSV/JSON, catálogo de fuentes y metodología.

## Advertencia

No es un servicio oficial, no recibe denuncias y no debe usarse para afirmar que un establecimiento cumple o incumple solamente por su presencia o ausencia en una lista.
